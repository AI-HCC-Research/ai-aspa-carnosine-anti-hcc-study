## ④ 输入信息

- **输入文件**：ASPA-肌肽分子对接复合物三维结构（PDB 格式），
  即 `data/ASPA_Carnosine_complex.pdb`（源自 AutoDock 对接产出结果）；
- 上传至 biobb 平台后由 MDSetup 工作流自动完成体系准备与模拟。

## ⑤ 关键参数

MDSetup 工作流关键步骤（顺序执行）：

1. 受体预处理：去结晶水、加氢、侧链修复（pymol / fixsidechain 模块）；
2. 复合物盒子构建与溶剂化（editconf / solvate 模块）；
3. 加离子中和（genion 模块）；
4. 能量最小化（GROMACS steepest descent）；
5. NVT 恒温平衡 → NPT 恒温恒压平衡；
6. 成品 MD 模拟，导出坐标轨迹即 `biobb.MDsetup.xtc`
   （拓扑 `biobb.MDsetup.gro`）。

| 参数项   | 数值                                         |
| ----- | ------------------------------------------ |
| 力场    | amber99sb-ildn                             |
| 水模型   | TIP3P                                      |
| 模拟总时长 | 300 ns                                     |
| 产出帧数  | 约 50 帧（`results/UMAP_ASPA_trajectory.png`） |

# ⑧ 与本提交包的关系

- 平台产出 `biobb.MDsetup.xtc / .gro` 是 `main.py`（UMAP 分析）的输入，
  获取方式见 `data/README.md`；
- 平台上的 MD 模拟属于**子任务1（蛋白质动力学模拟）工作内容；
  本提交包内的 UMAP 分析代码为团队原创，仅**调用平台产出的数据文件。
