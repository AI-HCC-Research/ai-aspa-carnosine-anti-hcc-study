# 数据来源与获取方式说明

## 一、随包提供的数据 (`data/` 目录)

| 文件                                               | 内容                          | 来源                                    |
| ------------------------------------------------ | --------------------------- | ------------------------------------- |
| `ASPA.csv`                                       | yaTCM 支路 45 个 IFD 复合物的对接分数表 | 【自产】Schrödinger IFD 结果汇总              |
| `A3_MGPT_molgpt_only.csv`                        | MolGPT 生成的 5,000 个候选分子(去重后) | 【自产】`src/2_directed_generation.py` 输出 |
| `A3_MGPT_machine_filter.csv`                     | MolGPT 分子经机器过滤后的子集          | 【自产】统一筛选流程中间产物                        |
| `open_conformations/open_conformation_01-15.pdb` | ASPA 开放构象集合(15个), 用于口袋稳健性验证 | 【自产】项目组构象分析生成                         |

## 二、公开数据集 (未随包, 需自行下载)

### 1. ZINC-250K (MolGPT 训练集)

- **用途**: MolGPT 生成模型预训练 (250,000 个类药 SMILES)
- **来源**: ZINC15 数据库子集, 经 MolGPT 作者清洗的版本
- **获取**: <https://github.com/devalab/molgpt> (随仓库提供 `250k_rndm_zinc_drugs_clean_3.csv`)
- **许可**: ZINC 数据库免费学术使用

### 2. PDBbind v2019 refined set (XGBoost 训练集)

- **用途**: XGBoost 亲和力模型训练 (4,849 个复合物)
- **来源**: PDBbind 数据库 v2019 精炼集
- **获取(免注册镜像)**: DeepChem S3 —
  `https://deepchemdata.s3-us-west-1.amazonaws.com/datasets/pdbbind_v2019_refined.tar.gz`
- **官方站(需注册)**: <http://www.pdbbind.org.cn/>
- **解析方式**: index 文件中 -logKd/Ki 位于第 4 列 (代码: `src/3_unified_screening.py` 的 `parse_pdbbind_index`)
- **许可**: 学术免费使用

### 3. yaTCM  中药成分库 (虚拟筛选库)

- **用途**: yaTCM 支路 47,696 个中药小分子的 Schrödinger 逐级筛选
- **来源**: yaTCM (<http://cadd.pharmacy.nankai.edu.cn/yatcm/>)&#x20;
- **获取**: 官网注册后免费下载 SDF 格式分子库 (下载时间: 2026年)
- **许可**: 学术免费使用
- **说明**: 原始库文件较大(数百MB)未随包; LigPrep 处理后的库为 IFD 日志中的 `ligprep_HY_yatcm.sdf`

## 三、自产中间数据 (已随包于 `results/`)

- `directed_qed_5000.csv` — MolGPT 定向生成 5,000 分子清单
- `prefilter_top500.csv` — QED 抽样 Top500
- `final_top20_xgboost.csv` / `final_top20_consensus.csv(.xlsx)` — 精排与双榜共识结果
- `ablation_perseed.csv` / `lowdata_results.csv` — 消融与低数据量评估记录

## 四、分子动力学数据 (已随包于 `md_analysis/data/`)

- GROMACS 2025.4 轨迹分析输出: `pic.rmsd/rmsd2/rmsd3/rmsf/area/gyrate/hbnum.xvg`
- gmx\_MMPBSA 1.6.4 输出: `FINAL_RESULTS_MMPBSA.dat`, `FINAL_DECOMP_MMPBSA.dat`
- 原始轨迹(.xtc, 数十GB)未随包; .xvg/.dat 已足够重绘全部 MD 图件 (`figures_src/fig_md_analysis.py`)
