# 路线A — MolGPT 生成式虚拟筛选

> 全流程为 **纯代码可复现** 

## 流程总览

```
步骤1  MolGPT 模型训练与定向生成
        ZINC-250K 预训练 → 定向采样 5,000 个高QED分子
            │
步骤2  筛选与分子对接
        5,000 → 2D规则过滤+去重 3754 → QED抽样 Top500
        → 三维构象生成 → Vina/GNINA对接 499
            │
步骤3  XGBoost 粗筛
        499 个对接pose → 55维特征提取 → XGBoost打分 → Top20
            │
步骤4  Top10 最终结果
        与 yaTCM 支路双榜共识 → final_top10_candidates
        (肌肽 Carnosine 综合排名第一)
```
