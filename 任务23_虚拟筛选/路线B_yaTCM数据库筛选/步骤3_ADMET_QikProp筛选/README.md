# 步骤3 — ADMET 性质筛选 (QikProp)

## 目的

对 58,048 个构型做类药性/ADMET 过滤, 剔除不满足成药性规则的分子。

## 筛选量级

**58,048 → 22,227 个分子**

## 方法

- Virtual Screening Workflow (VSW) 中分批调用 QikProp, 共 **60 个批次**
  (输入文件命名 `VSW-ASPA-4MXU-QIKPROP-001~060-in.maegz`);
- 过滤标准: Lipinski 五规则 + 反应性/毒性警示。

| -------------------------------- | ---------------------------------------- |
| `批次结果/批次示例_QIKPROP-001-in.maegz` | 第 1 批次输入示例 (Maestro 格式, 可用 Maestro 打开核对) |

> 全部 60 批次文件共 66 MB, 超出提交包体积未全部随包; 批次命名规则与数量如上,
> 原始文件留存于项目工作站 `01_虚拟筛选与柔性对接流程数据/05_ADMET筛选_QikProp批次文件/`。
